# DropMe Go — Designated Driver Service

DropMe Go is a responsive, mobile-friendly website for a designated driver service in Sri Lanka. It helps customers arrange a professional driver to drive their own vehicle safely to their destination.

## Features

- Responsive, mobile-first design
- Service and pricing package sections
- Online booking request form
- WhatsApp booking integration
- Direct phone-call functionality
- Floating Call and WhatsApp buttons
- Company information and contact section
- Responsive navigation and footer
- PHP-powered contact details and dynamic copyright year

## Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Google Fonts

## Purpose

The project provides a simple and accessible online platform for customers to explore designated driver services, compare packages, and contact DropMe Go to request a booking.
